# لوحة تحكم جمعية القرآن الكريم

لوحة تحكم بواجهة عربية (RTL) مبنية بـ React + Vite.

## الصفحات
- **تسجيل الدخول**: حماية كل الصفحات بحساب مدير.
- **لوحة التحكم**: ملخص التلاميذ والمعلمين والتسجيلات وتحصيل الرسوم.
- **التلاميذ**: الاسم واللقب، المستوى، اسم الولي، هاتف الولي، تاريخ الميلاد، القسم (إضافة / تعديل / حذف / بحث / تصفية).
- **المعلمون**: اللقب، الاسم، تاريخ البدء، رقم الهاتف.
- **التسجيلات**: تسجيل التلاميذ لكل سنة دراسية مع الرسوم والمبلغ المدفوع وحالة الدفع.
- **الإعدادات العامة**: معلومات الجمعية، قوائم المستويات والأقسام، تغيير حساب الدخول، نسخ احتياطي (تصدير / استيراد JSON).

## التشغيل
```bash
npm install
npm run dev        # للتطوير
npm run build      # بناء النسخة النهائية في مجلد dist
```

## الحساب الافتراضي
- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

غيّرهما من **الإعدادات العامة ← حساب الدخول**.

## ملاحظات
- البيانات تُحفظ في `localStorage` داخل المتصفح (لا يوجد خادم). صدّر نسخة احتياطية بانتظام.
- التحقق من الدخول يتم في المتصفح فقط، ولا يوفّر حماية حقيقية للبيانات. لاستعمال حقيقي اربط اللوحة بـ API وقاعدة بيانات.
- المشروع يستعمل `HashRouter` فيعمل على أي استضافة ثابتة دون إعداد إضافي.
